# GET /api/tags/

List all tags, sorted alphabetically.

Retrieves a complete list of all existing tags, sorted in alphabetical order.

## Endpoint

```
GET /api/tags/
```

## Response

| Status | Description |
|--------|-------------|
| **200** | Successfully retrieved the list of tags. Returns `application/json`. |
